# Contributing

Contributions are welcome: bug fixes, tests, new detections, documentation.

## How

1. Fork the repository and create a branch.
2. Install: `pip install -e ".[dev]"`
3. Make your change and add tests. Run `pytest` and `ruff check src tests`.
4. Open a pull request describing what and why.

## Rules

- Never commit real phishing samples, API keys or personal data. Test data must be synthetic.
- Keep to the existing style: typed, documented, graceful error handling.
